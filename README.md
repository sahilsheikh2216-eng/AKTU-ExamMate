# AKTU ExamMate

An AKTU previous-year question paper analysis and AI-powered study planning application.

## Features
- Multiple AKTU subject support
- Previous-year question extraction
- Repeated question analysis
- Study plan generation

## Technologies
- Python
- Flask
- Pandas
- Sentence Transformers
- HTML, CSS and JavaScript

## Run locally

```bash
pip install -r requirements.txt
python app.py
